# AIToken
## 一、项目概述
AIToken 是部署在 BSC（币安智能链）主网上，面向AI分布式算力赛道的去中心化BEP20通证项目。项目所有发行规则、分配机制、解锁逻辑全部写入链上智能合约，公开透明、不可篡改、无法人为干预。
项目无预挖、无增发后门，团队、机构、国库份额全部采用线性时间锁分批解锁；初始流动性足额注入PancakeSwap，从机制上规避大额砸盘，保障普通持有者长期权益。

## 二、基础参数
- 公链：BSC（Binance Smart Chain）主网
- 代币名称：AIToken
- 代币符号：AI

- 代币标准：BEP20

## 四、代币分配总方案（总量1亿枚）
1. **流动性池 1000万枚**
全额注入 PancakeSwap AIToken/BNB 交易对，为二级市场提供交易深度；流动性长期留存，保障正常买入卖出。

2. **国库储备 3500万枚**
存入国库专属时间锁合约，按月线性解锁。解锁资金仅限用于AI算力研发、服务器搭建、生态合作、社区激励、日常运营，所有链上流向可在BSCScan查验。

3. **质押挖矿激励 2000万枚**
全部划入挖矿奖励池，用户质押AIToken即可持续获得奖励；奖励匀速按时间释放，杜绝短期大额抛压。

4. **团队与机构份额 2500万枚**
单独部署时间锁合约，设置中长期解锁周期，按月分批释放；禁止一次性大额提现，所有解锁记录全网可查。

## 五、核心功能说明
### 1. 二级市场交易
- 交易平台：PancakeSwap V2
- 交易对：AIToken / BNB
- 支持MEV保护、自定义滑点，降低机器人抢跑与交易失败概率。

### 2. 质押挖矿
- 用户将钱包内AIToken存入挖矿合约，按质押时长持续产出奖励；
- 奖励匀速释放，质押时间越长累计收益越高；
- 支持随时解押，本金即时退回钱包，无强制锁仓。

### 3. 全份额链上锁仓机制
国库、团队、机构代币统一托管于独立时间锁合约：
- 解锁数量、解锁时间固化在合约内，任何人不可修改；
- 项目方无权限提前解锁、批量划转；
- 余额、解锁记录、历史提现记录可在BSCScan实时查询。

### 4. 去中心化透明机制
- 所有合约开源可核验，无管理员增发、强制销毁、后台划转权限；
- 流动性余额、锁仓余额、矿池余额永久公开可查；
- 所有操作行为链上留痕，全程可追溯。
